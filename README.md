## English

Name File Cleaner is a lightweight, browser-based tool that automates renaming large batches of files. Perfect for standardizing file names, preparing uploads for platforms with naming restrictions, or decluttering downloads.

### Features

| Feature | Description |
|---------|-------------|
| **Batch Processing** | Process hundreds of file names at once, one per line |
| **Special Character Removal** | Strip unsafe characters that break shells or URLs |
| **Space Normalization** | Replace spaces with underscores (`_`) or hyphens (`-`) |
| **Case Conversion** | Convert to lowercase or uppercase |
| **Prefix/Suffix** | Add custom prefixes/suffixes or remove unwanted ones |
| **Extension Preservation** | Keep `.jpg`, `.pdf`, etc. intact |
| **Client-Side Only** | All operations in your browser — no files leave your device |

### How It Works

1. **Input** — Paste file names (one per line) or upload a `.txt` file
2. **Configure** — Select cleaning options
3. **Preview** — Review before/after transformations
4. **Export** — Copy to clipboard or download as `.csv`

### Privacy

> 🔒 **Your data stays on your device.** This tool runs entirely in your browser. No server-side processing means no logs and no tracking.

## Deutsch

DateiCleaner ist ein leichtgewichtiges, browserbasiertes Tool, das die Umbenennung großer Dateimengen automatisiert. Perfekt zum Standardisieren von Dateinamen, Vorbereiten von Uploads oder Aufräumen von Downloads.

### Funktionen

| Funktion | Beschreibung |
|----------|--------------|
| **Stapelverarbeitung** | Hunderte Dateinamen gleichzeitig, einer pro Zeile |
| **Sonderzeichen entfernen** | Unsichere Zeichen, die Shells oder URLs brechen |
| **Leerzeichen normalisieren** | Ersetzt Leerzeichen durch `_` oder `-` |
| **Groß-/Kleinschreibung** | Konvertiere zu Klein- oder Großbuchstaben |
| **Präfix/Suffix** | Eigene Präfixe/Suffixe hinzufügen oder entfernen |
| **Erweiterung erhalten** | `.jpg`, `.pdf`, etc. unberührt lassen |
| **Nur Client-seitig** | Alles im Browser — keine Dateien verlassen dein Gerät |

### Funktionsweise

1. **Eingabe** — Dateinamen einfügen (eine pro Zeile) oder `.txt` hochladen
2. **Konfigurieren** — Bereinigungs-Optionen wählen
3. **Vorschau** — Vorher/Nachher prüfen
4. **Exportieren** — In Zwischenablage kopieren oder als `.csv` herunterladen

### Datenschutz

> 🔒 **Deine Daten bleiben auf deinem Gerät.** Das Tool läuft vollständig im Browser. Keine serverseitige Verarbeitung bedeutet keine Logs und kein Tracking.
